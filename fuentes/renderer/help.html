    Bienvenido a DiffCore
    🍎 macOS 🪟 Windows 🐧 Linux

    DiffCore es una suite multiplataforma de comparación y sincronización de alto rendimiento, diseñada para replicar y modernizar con fidelidad milimétrica la experiencia de Beyond Compare 5.

    Permite comparar código fuente, directorios completos, imágenes, hojas de cálculo, archivos binarios y multimedia con algoritmos paralelos ultra-rápidos en JavaScript y C++, ofreciendo latencias inferiores a 40ms incluso en carpetas con decenas de miles de archivos.

    💡
    Zero Dependencias de Java DiffCore cuenta con un motor de descompilación Java nativo en WebAssembly. Puedes abrir archivos .class compilados y contenedores .jar, .war y .ear sin tener instalado Java (ni JDK ni JRE) en tu equipo.

    🌟 Módulos Principales de DiffCore

    Herramienta Descripción Atajo Rápido
    📁 Folder Compare Comparación recursiva lado a lado de carpetas y empaquetados. Cmd/Ctrl + 1
    📝 Text Compare Alineación Myers Diff, edición interactiva y detección de cambios intra-línea. Cmd/Ctrl + 2
    ☕ Java to Source Descompilación al vuelo de bytecode .class y apertura de .jar. Automático
    🔀 Folder Merge / Sync Fusión de 3 vías y sincronización espejo/actualización con reglas de seguridad. Menú Sesiones
    🔢 Hex Compare Inspección hexadecimal byte a byte para ejecutables y datos binarios. Automático / Tarjeta
    📊 Table Compare Comparación celda a celda de libros Excel (.xlsx) y .csv. Tarjeta
    🖼️ Picture Compare Superposición y detección de tolerancias en imágenes PNG, JPG, WebP, SVG. Tarjeta
    🎵 Media Compare Análisis de metadatos ID3, tasas de bits y codecs de audio y video. Tarjeta

    Pantalla de Inicio y Gestión de Sesiones

    La pantalla de inicio de DiffCore actúa como centro de control centralizado, idéntico a Beyond Compare 5, permitiendo lanzar comparadores con un solo clic o arrastrando elementos directamente sobre los iconos de herramientas.

    Arquitectura Visual de la Pantalla de Inicio DiffCore 1.0

    1. Panel Lateral de Sesiones

    • Auto-saved (Auto-guardadas): DiffCore registra de forma inteligente las últimas comparaciones realizadas y las agrupa automáticamente en carpetas cronológicas (Today, Yesterday, 2 days ago, etc.). Al hacer doble clic sobre cualquier sesión, se reabren de inmediato las rutas exactas.
    • Guardar Sesión: Puedes nombrar y fijar comparaciones recurrentes para abrirlas con un solo clic.
    • Filtro de búsqueda: Escribe en el campo de texto inferior para filtrar instantáneamente el árbol de sesiones.

    2. Barra de Telemetría en Vivo

    En la base de la pantalla de inicio, DiffCore incluye un panel de estado en vivo que monitoriza:

    • Consumo de RAM: Monitor en tiempo real de la memoria del proceso con barra de color dinámico.
    • Latencia del Motor: Tiempo de ejecución medido en centésimas de segundo.
    • Estado del Motor: Notifica si el algoritmo Myers Diff está activo o en espera.

    Comparador de Carpetas (Folder Compare)

    El Comparador de Carpetas permite alinear y comparar recursivamente estructuras completas de directorios o empaquetados en dos paneles independientes (Izquierda y Derecha).

    🎯 Filtros de Visualización de la Barra de Herramientas

    Igual que en Beyond Compare 5, la barra superior dispone de tres botones clave para filtrar los resultados de la comparación:

    Botón Nombre Comportamiento
    ✳ All Mostrar Todo Muestra el árbol completo, incluyendo archivos idénticos, modificados y huérfanos.
    ≠ Diffs Diferencias Oculta los archivos iguales y despliega exclusivamente los elementos con cambios o archivos que solo existen en un lado.
    ＝ Same Iguales Muestra únicamente los archivos idénticos en ambos lados.

    📋 Menús Contextuales Nativos (Clic Derecho)

    Al hacer clic derecho sobre cualquier fila, se despliega el menú contextual auténtico de Beyond Compare:

    • Abrir / Abrir con: Ejecuta el archivo con el editor de DiffCore o aplicaciones externas (Finder / Explorador de archivos, Terminal, o aplicación predeterminada del sistema).
    • Copiar a la derecha / izquierda: Copia quirúrgica del elemento o carpeta seleccionada preservando permisos y marcas de tiempo.
    • Comparar Contenido (=?): Abre el modal de comparación profunda para verificar sumas de comprobación CRC32, SHA-256 o comparación binaria byte a byte en segundo plano con motor multi-hilo.
    • Eliminar: Soporta envío seguro a la Papelera del sistema o borrado permanente forzado.
    📌
    Doble Clic Inteligente Al hacer doble clic sobre un archivo de código o texto, se abre una pestaña hija en el Comparador de Texto manteniendo el contexto del directorio. Si es una imagen o tabla, se abre en sus respectivos visores. Si es un archivo .class, se descompila automáticamente a código Java.

    Fusión de Carpetas (Folder Merge) y Sincronización (Sync)

    DiffCore incorpora herramientas profesionales de reconciliación de datos para ramas de Git, copias de seguridad de servidores y despliegues sincronizados.

    🔀 Folder Merge (Fusión 3-Way de Carpetas)

    Compara simultáneamente tres ubicaciones:

    • Left (Izquierda): Tu versión de trabajo (Your branch / changes).
    • Base (Centro): El ancestro común (Base ancestor).
    • Right (Derecha): La versión remota o de otros desarrolladores (Their changes).

    DiffCore detecta automáticamente adiciones no conflictivas y resalta los conflictos reales donde el mismo archivo fue modificado en ambas ramas.

    🔄 Folder Sync (Sincronización de Carpetas)

    Permite mantener dos carpetas sincronizadas bajo cuatro métodos estándar:

    • Update Right (Actualizar Derecha): Copia archivos nuevos o más recientes desde la izquierda hacia la derecha. No elimina archivos huérfanos.
    • Update Left (Actualizar Izquierda): Copia archivos nuevos o más recientes desde la derecha hacia la izquierda.
    • Mirror Right (Espejo a Derecha): Hace que el lado derecho sea una copia idéntica del izquierdo. Copia los archivos modificados y elimina de la derecha aquellos que no existan en la izquierda.
    • Mirror Left (Espejo a Izquierda): Hace que el lado izquierdo sea una copia idéntica del derecho.
    ⚠️
    Vista Previa Antes de Ejecutar Antes de aplicar cambios destructivos en modo Espejo, DiffCore presenta una lista completa de acciones (copias y eliminaciones previstas) para revisión y confirmación del usuario.

    Comparador de Texto (Text Compare)

    El Comparador de Texto implementa el algoritmo Myers Diff de longitud mínima con alineación bi-dimensional idéntica a Beyond Compare 5.

    ✨ Características Clave del Motor de Texto

    • Alineación Intra-línea: Cuando dos líneas son similares pero difieren en algunas palabras o caracteres, DiffCore resalta en rojo brillante las diferencias exactas dentro de la línea.
    • Líneas Fantasma (Ghost Lines): Si un bloque de código fue insertado o eliminado, el lado opuesto dibuja automáticamente un relleno estriado para mantener sincronizado el número de línea visual en ambos paneles.
    • Edición en Vivo: Puedes escribir, pegar o borrar código directamente en cualquiera de los dos lados. El motor recalcula las diferencias de forma instantánea en memoria sin bloquear la interfaz.
    • Deshacer y Rehacer Ilimitado: Cada panel mantiene su pila de cambios independiente con Cmd/Ctrl + Z y Cmd/Ctrl + Y.
    • Riel de Visión General (Overview Rail): Una franja vertical en el extremo derecho muestra un mapa térmico de todo el archivo con marcas de color rojo (diferencias) y verde (inserciones) para saltar rápidamente a cualquier punto del documento.

    🔍 Búsqueda y Reemplazo Integrado

    Presiona Cmd/Ctrl + F para activar la barra de búsqueda y Cmd/Ctrl + H para reemplazar texto con soporte para:

    • Coincidencia de mayúsculas y minúsculas (Match Case).
    • Palabras completas (Whole Words).
    • Expresiones regulares (Regex).

    Fusión 3-Way de Texto (Text Merge) y Editor Rápido

    La herramienta de Text Merge está diseñada para resolver colisiones y conflictos complejos al integrar ramas de control de versiones o conciliar diferentes revisiones de código fuente.

    🔀 Disposición de los 3 Paneles Superiores y Panel de Salida

    A diferencia de la comparación estándar de dos vías, la fusión 3-way presenta tres paneles de entrada en la parte superior y un panel de resultado consolidado en la parte inferior:

    • Panel Izquierdo (Left / Your branch): Contiene tus cambios locales en curso.
    • Panel Central (Center / Base Ancestor): La versión base u origen común antes de que ambas partes realizaran modificaciones.
    • Panel Derecho (Right / Their branch): La versión remota o de tu compañero de equipo.
    • Panel Inferior (Output / Merged Result): El archivo final resultante donde se consolidan las líneas automáticamente resueltas y los bloques seleccionados manualmente.

    ⚡ Adopción con un Solo Clic

    Junto a cada sección en conflicto, DiffCore sitúa botones de acción rápida:

    • Tomar de Izquierda (Take Left): Inyecta el contenido de tu rama local directamente en la posición correspondiente del archivo de salida.
    • Tomar de Derecha (Take Right): Inyecta el bloque de la rama remota.
    • Conservar Base (Keep Center): Descarta ambos cambios concurrentes y preserva la versión base original.

    📝 Editor Rápido de Texto (Text Edit)

    Si solo necesitas examinar, modificar o depurar un archivo individual sin abrir un comparador de dos paneles, DiffCore incluye el modo Text Edit con numeración de líneas, detección de sintaxis, estadísticas en vivo y atajos de guardado estándar.

    Soporte Java al Vuelo: Descompilador y Empaquetados
    ☕ Java class to source Sin JRE/JDK

    DiffCore incorpora soporte nativo para ingeniería inversa y comparación de ejecutables Java bytecode (.class) y contenedores de empaquetados (.jar, .war, .ear, .zip), replicando la función "Java class to source" de Beyond Compare 5.

    Flujo de Trabajo del Motor de Descompilación y Empaquetados Vineflower Wasm Engine

    1. Descompilación al Vuelo de Clases (.class)

    Al abrir cualquier archivo .class en el Comparador de Texto:

    • El motor Vineflower Wasm decompila el bytecode en memoria en menos de 100ms.
    • Se presenta como código fuente Java estándar con numeración de líneas y resaltado de sintaxis completo.
    • En la barra de estado inferior se indica claramente el formato: Java class to source ▾.
    • Seguridad: El archivo descompilado queda marcado en modo Solo Lectura para evitar corromper el binario compilado original.

    2. Apertura de Contenedores (.jar, .war, .ear)

    DiffCore trata los empaquetados Java como carpetas de primer nivel:

    • Puedes seleccionar un archivo .jar tanto en el lado izquierdo como en el derecho del Comparador de Carpetas.
    • La estructura interna (paquetes com/empresa/..., META-INF/, archivos .properties, .xml) se expande y compara árbol contra árbol.
    • Al hacer doble clic sobre cualquier clase interna, se abre y descompila inmediatamente en el Comparador de Texto.

    3. Redirección Inteligente Drag & Drop

    Si arrastras un archivo .jar, .war o .ear sobre el Comparador de Archivos de Texto:

    • DiffCore detecta que es un contenedor comprimido.
    • Cierra automáticamente la pestaña de texto para no dejar pestañas vacías abiertas.
    • Abre de inmediato el Comparador de Carpetas con el empaquetado desplegado y listo para comparar.

    Comparador Hexadecimal (Hex Compare)

    El Comparador Hexadecimal permite inspeccionar y comparar archivos binarios arbitrarios (ejecutables .exe, .dylib, .so, imágenes de disco .iso o archivos corruptos) a nivel de bytes.

    Diseño del Panel Hexadecimal

    La vista organiza cada archivo en tres columnas tradicionales:

    • Offset (Dirección): Posición del byte en formato hexadecimal (ej. 00000000, 00000010).
    • Datos Hexadecimales: 16 bytes por fila representados en base 16 (ej. 7F 45 4C 46 ...). Los bytes modificados se resaltan en color rojo.
    • Representación ASCII: Visualización de caracteres alfanuméricos legibles en el lateral derecho, reemplazando caracteres de control por puntos (.).

    Alerta de Archivos Binarios No Soportados

    Si intentas abrir un archivo binario directamente en el comparador de texto plano, DiffCore detiene la carga para evitar congelamientos o caracteres basura y despliega un diálogo emergente:

    ⚠️
    Archivo Binario No Soportado como Texto "El archivo seleccionado contiene datos binarios que no corresponden a texto plano ni a clases Java compiladas. ¿Deseas abrirlo en el Comparador Hexadecimal?"

    Al presionar "Abrir en Comparador Hexadecimal", DiffCore redirige automáticamente el archivo al visor binario y cierra de forma limpia la sesión de texto.

    Comparador de Tablas (Table Compare)

    Diseñado para analizar diferencias en hojas de cálculo y bases de datos tabulares sin necesidad de abrir suites ofimáticas pesadas como Excel o LibreOffice.

    Formatos Soportados

    • Microsoft Excel: .xlsx, .xls
    • Valores separados por comas: .csv
    • Valores separados por tabuladores: .tsv

    Funciones de Comparación

    • Alineación por Fila Clave: Alinea filas según la clave primaria o columna identificadora para evitar desfases si se agregaron o eliminaron registros intercalados.
    • Resaltado Celda por Celda: Resalta en rojo las celdas con valores discrepantes y en verde las celdas agregadas.
    • Detección de Tipos de Datos: Discrimina automáticamente entre números, fechas, texto y fórmulas.

    Comparador de Imágenes (Picture Compare)

    Permite inspeccionar diferencias visuales sutiles entre capturas de pantalla, iconos, banners y diseños web.

    Formatos Compatibles

    PNG, JPEG / JPG, GIF, WebP, SVG, BMP, ICO.

    Modos de Visualización

    • Lado a Lado (Side-by-Side): Muestra ambas imágenes sincronizando el nivel de zoom y el desplazamiento del lienzo.

    • Umbral de Tolerancia: Permite ignorar pequeñas variaciones de compresión JPEG o anti-aliasing.

    Reglas de Comparación y Configuración (Options)

    DiffCore te permite personalizar minuciosamente qué diferencias se consideran relevantes y cómo se comportan los motores de análisis mediante el diálogo de Opciones (Cmd + , en macOS / Ctrl + , en Windows/Linux).

    ⚙️ Criterios de Comparación de Carpetas

    En la configuración de sesiones de carpetas puedes configurar los métodos de validación:

    • Tamaño de archivo: Considera diferentes dos archivos con distinto número de bytes (rápido).
    • Fecha y hora (Timestamp): Compara la fecha de última modificación, con tolerancia opcional de 2 segundos para sistemas de archivos FAT/FAT32.
    • Contenido por Hash (CRC32 / MD5 / SHA256): Calcula el hash en segundo plano para garantizar que dos archivos son idénticos bit a bit.

    🔤 Reglas de Comparación de Texto

    • Ignorar espacios en blanco: Omite diferencias provocadas exclusivamente por indentaciones, espacios finales o espacios consecutivos.
    • Ignorar finales de línea (CRLF vs LF): Crucial al trabajar en proyectos multiplataforma entre Windows y Unix/macOS para evitar que todas las líneas aparezcan marcadas como modificadas.
    • Ignorar mayúsculas y minúsculas (Case Insensitive): Trata palabras con diferencias de capitalización como equivalentes cuando no afecten el significado semántico.

    🎨 Apariencia e Idioma

    Puedes alternar entre el Tema Oscuro de Alto Contraste (diseñado para largas jornadas de trabajo con acentos Beyond Compare 5) y el Tema Claro, así como alternar instantáneamente entre 6 idiomas (Español, Inglés, Portugués, Francés, Italiano y Ruso) sin reiniciar la aplicación.

    Línea de Comandos (CLI) e Integración con Git

    DiffCore puede lanzarse directamente desde cualquier terminal de macOS, Linux o PowerShell/CMD de Windows, y puede configurarse como la herramienta gráfica oficial de diferencias y resolución de conflictos de Git.

    1. Uso desde la Terminal

    # Comparar dos archivos de texto o clases Java:
diffcore archivo1.java archivo2.java

# Comparar dos carpetas o empaquetados .jar:
diffcore /ruta/servidor/app.jar /ruta/local/app.jar

# Fusión de 3 vías (Left, Right, Base, Output):
diffcore mi_codigo.js codigo_remoto.js ancestro.js salida_resuelta.js

    2. Configurar DiffCore como Git DiffTool y MergeTool

    Ejecuta los siguientes comandos en tu terminal para registrar DiffCore en tu configuración global de Git (~/.gitconfig): 

    # 1. Configurar herramienta de comparación (git diff)
git config --global diff.tool diffcore
git config --global difftool.diffcore.cmd "diffcore \"\$LOCAL\" \"\$REMOTE\""
git config --global difftool.prompt false

# 2. Configurar herramienta de fusión (git merge)
git config --global merge.tool diffcore
git config --global mergetool.diffcore.cmd "diffcore \"\$LOCAL\" \"\$REMOTE\" \"\$BASE\" \"\$MERGED\""
git config --global mergetool.diffcore.trustExitCode true

    A partir de ese momento, ejecutar git difftool o git mergetool abrirá automáticamente DiffCore en una pestaña independiente para resolver los cambios.

    Glosario y Solución de Problemas (Troubleshooting)

    📚 Glosario de Conceptos

    • Myers Diff: Algoritmo de optimización que encuentra la secuencia de edición más corta posible entre dos secuencias de texto. Garantiza la menor cantidad de líneas añadidas y borradas.
    • Línea Fantasma (Ghost Line): Fila vacía sintética generada por DiffCore para alinear horizontalmente bloques de código donde un lado carece de las líneas presentes en el otro.
    • Bytecode Java: Código binario compilado (archivo .class) interpretado por la máquina virtual Java. DiffCore lo descompila a código fuente Java legible.
    • CRC32 / SHA-256: Algoritmos criptográficos y de suma de comprobación que validan si el contenido exacto de dos archivos es idéntico byte por byte sin necesidad de abrirlos visualmente.
    • Archivo Huérfano: Archivo o carpeta que existe en uno de los lados de la comparación pero no tiene contraparte en el otro.

    ❓ Preguntas Frecuentes y Solución de Problemas

    ¿Por qué al arrastrar un .jar a Texto me envía a Carpetas?

    Un archivo .jar es en realidad un archivo comprimido que contiene paquetes y múltiples clases compiladas. DiffCore detecta automáticamente esta estructura y lo abre en el Comparador de Carpetas, cerrando la pestaña de texto para permitirte navegar todos sus paquetes.

    ¿Puedo modificar una clase .class descompilada y guardarla?

    No directamente sobre el binario compilado. Los archivos .class se cargan en modo solo lectura para proteger el archivo de corrupción. Para modificar el código, puedes copiar el texto descompilado y guardarlo en un archivo con extensión .java.

    ¿Cómo mantener abierta esta ventana de ayuda mientras uso DiffCore?

    Esta ventana de ayuda es un proceso independiente. Puedes posicionarla al lado de tu ventana principal de DiffCore, moverla a un segundo monitor o presionar el botón "Abrir en Navegador" en la esquina superior derecha para leerla en una pestaña de Google Chrome, Safari, Firefox o Edge.
